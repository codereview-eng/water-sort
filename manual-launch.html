数独小游戏 · 上架 Telegram 与 Monetag 变现手册

01托管游戏文件(约 5 分钟)

Telegram Mini App 只认 HTTPS URL。sudoku.html 是单文件,放任何静态托管都行,推荐零成本方案:

  1. GitHub 建一个公开仓库,把 sudoku.html 改名 index.html 上传。
  2. 仓库 Settings → Pages → Source 选 main 分支根目录,保存。
  3. 约 1 分钟后得到 https://你的用户名.github.io/仓库名/,浏览器打开确认能玩。

备选:Cloudflare Pages、Netlify、Vercel 均免费,拖文件即可。有自己的服务器/域名也可以,只要 HTTPS。

02BotFather 创建 Mini App(约 5 分钟)

  1. Telegram 搜 @BotFather → 发送 /newbot,按提示起名(bot 用户名须以 bot 结尾,如 MySudokuGameBot)。
  2. 发送 /newapp → 选刚建的 bot → 填标题「数独」、简介、上传一张 640×360 截图(用游戏截图即可)→ Web App URL 填第 1 步的 HTTPS 地址 → 设置短名(如 sudoku)。
  3. 完成后你的游戏直链是 t.me/你的bot用户名/sudoku,发到任何聊天即可打开。
  4. 可选:/setmenubutton 把 bot 聊天窗底部按钮也指到游戏。

03Monetag 接广告开始赚钱(约 10 分钟)

  1. 到 monetag.com 注册发布者账号(个人可用,可用 Telegram 登录)。
  2. 后台 New Site → 类型选 Telegram Mini App,填你的 t.me 直链,等审核通过(通常很快)。
  3. 该站点下新建广告位:选 Rewarded Interstitial(激励插屏),得到一个数字 zone id。
  4. 改 sudoku.html 两处(文件里有注释标记):
<!-- head 里:去掉注释并替换两处 YOUR_ZONE_ID -->
<script src="https://libtl.com/sdk.js"
        data-zone="123456" data-sdk="show_123456"></script>

// script 里:
const MONETAG_ZONE_ID = '123456';
  1. 重新上传托管,完成。之后三个广告挂点(提示用完 +1、错满三次续命、免费局用完换一盘)都会播真广告并计入收益。
  2. 提现:Monetag 后台 Payments,支持 PayPal、USDT、Payoneer 等,最低 $5 起付,NET-30 周期。

没填 zone id 时游戏自动走「演示模式」(模拟播广告后照常发奖励),方便你先体验完整流程;真广告只在真实 Telegram 客户端内展示。

04收入怎么算 · 怎么做大

变量说明
展示量三个挂点都是用户主动触发,人均每局约 0-3 次广告;收入 = 展示 × eCPM ÷ 1000。
eCPM随受众地区浮动(欧美 tier-1 明显高于其他地区),Monetag 后台可看分国报表。
冷启动没有流量就没有收入。低成本起量:把 t.me 直链发进数独/益智类群组和频道、让完局分享按钮带直链裂变、Telegram Ads 少量投放。
后续可加每日挑战(固定 seed 全网同题)、排行榜(需加一个轻后端)、去广告内购(Telegram Stars)。
